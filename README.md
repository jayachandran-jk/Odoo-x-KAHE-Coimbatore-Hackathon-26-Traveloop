## 🚨 The Problem

> *"Planning a trip is often more stressful than the trip itself."*

Modern travelers face a multi-layered problem that no single tool currently solves end-to-end:

| Pain Point | Current Reality |
|---|---|
| 🧠 **Decision Fatigue** | Sifting through thousands of unranked, unfiltered attractions |
| 💸 **Budget Mismatch** | Itineraries that look great on paper but blow your wallet in reality |
| ⚡ **Logistical Conflicts** | Overlapping activities, closed venues, and unrealistic travel times |
| 🗣️ **Language Barriers** | No actionable help when you're stranded in a foreign country |
| 📦 **Generic Packing Lists** | One-size-fits-all lists that ignore destination-specific requirements |
| 💱 **Currency Confusion** | Mentally converting prices while trying to actually enjoy the journey |
| 🌐 **Language Isolation** | Planning tools available only in English, alienating billions of users |

---

## 💡 The Solution

**Traveloop** is not a directory. It's not a booking site. It's your **personal AI travel agent** that thinks, plans, and adapts entirely for you.

By combining **LLM-driven generation** (Gemini + Groq), real-time weather data, live interactive maps, geo-aware currency intelligence, and a curated destination knowledge base — Traveloop transforms a vague travel idea into a complete, conflict-free, budget-optimized experience in under **3 seconds**.

## 🏗 Core Features

### 1. 🤖 AI Trip Builder
The flagship feature. Define your destination, travel dates, and total budget — receive a fully structured, day-by-day travel plan in seconds.

- Complete **day-wise breakdown**: Hotels, Activities, Food, and Transport with individual cost estimates
- **Budget Scaling Logic**: A ₹5,000 trip and a ₹5,00,000 trip are fundamentally different experiences — the AI scales accommodation category, dining tier, and activity exclusivity accordingly
- All cost estimates rendered in the **user's detected local currency** with live exchange rates applied

### 2. 🎒 AI Smart Packing
Forget generic lists. Traveloop generates a packing list tailored to your exact destination, season, and planned activities.

- Each item includes a contextual **"Essential Reason"** — e.g., *"Pack a Dhoti — Mandatory attire for Tirumala temple entry"*
- Dynamically adjusts for climate, cultural norms, and activity type (trekking vs. beach vs. pilgrimage)

### 3. 🗺️ Interactive Map Integration *(Mapbox)*
Every generated itinerary is immediately visualized on a live, interactive map.

- Day-wise route plotting with optimized travel paths
- Place cards with destination photos (Unsplash), ratings, and opening hours
- Distance and travel-time estimates between each stop, feeding directly into conflict detection

### 4. ☁️ Weather-Aware Planning *(OpenWeather)*
The AI cross-references travel dates against real-time and historical weather forecasts.

- Proactive alerts: *"Heavy rainfall expected in Munnar on Day 3 — consider rescheduling the valley trek"*
- Packing list auto-adjusts based on forecasted weather conditions at the destination

### 5. 📱 SMS Trip Alerts *(Twilio)*
- Pre-departure SMS summary of the itinerary sent to the traveler and an optional emergency contact
- Day-of reminders for key activities and hotel check-in times
- Fully opt-in with explicit user consent during trip creation

### 6. 🌍 Community & Social *(Unsplash + Cloudinary + Socket.io)*
- Publish completed trips to the **community feed** with beautiful Unsplash-powered cover imagery
- **"Copy Trip"**: One click clones any public itinerary into your personal dashboard for editing
- Real-time feed updates powered by Socket.io

### 7. 📓 Travel Journal
- Document travel memories with AI-assisted entry generation
- Photos uploaded and served securely via Cloudinary

## ✨ Novelties & Competitive Edge

> What makes Traveloop fundamentally different from TripAdvisor, Google Travel, or MakeMyTrip?

### 1. 🎭 AI Mood Planner
Don't know *where* to go? Select your **Mood** — Adventure, Relax, Party, Culture, Romance, or Spiritual — and the AI selects the destination *and* crafts the entire experience for you. Zero input required beyond a feeling.

### 2. 🆘 Emergency Phrase Engine
Not a translator — a **survival toolkit**. For any destination country, instantly generates critical phrases (Police, Doctor, Lost Passport, I Need Help) complete with:
- The phrase in the **native script** of the destination country
- **Phonetic pronunciation** in Roman characters for confident speaking
- Context guidance on *when and how* to use each phrase

### 3. 🧠 AI Conflict Detection
The AI reads your full itinerary like a seasoned local guide and flags logical impossibilities before you even pack:
> *"The Meenakshi Temple closes at 12:30 PM. Your current slot ends at 12:15 PM with a 40-minute travel time — you won't make it."*

Automatically suggests time swaps, alternative venues, or buffer adjustments.

### 4. 💰 Budget Optimizer
Post-generation analysis identifies highest-spend categories and surfaces actionable savings:
> *"Switching to local dhabas in Tirupati instead of hotel restaurants saves approximately ₹3,300 over 3 days."*

Visual spend breakdown across Accommodation, Transport, Food, and Experiences.

### 5. ⚡ Smart "Add to Trip"
Click any suggested activity from the AI recommendation panel and it is **automatically injected** into your itinerary with correct day-and-time positioning — no drag-and-drop, no manual typing, no re-ordering.

### 6. 🏛️ Destination-Aware Fallback Knowledge Base
Even if the AI API is temporarily unavailable, Traveloop's curated knowledge base serves **real, site-specific** landmarks and logistics for 20+ Indian destinations — Tirupati, Kerala, Goa, Varanasi, and more. No generic placeholder content. Ever.

| Layer | What Adapts |
|---|---|
| **UI & Navigation** | All menus, buttons, labels, tooltips, and error messages |
| **AI-Generated Content** | Itineraries, packing lists, and travel tips prompted and returned in the user's chosen language |

## 💱 Smart Currency System

Traveloop makes currency **invisible** to the traveler. There is zero manual conversion at any point in the experience.

```
User opens app in India  →  Detects IN locale  →  All figures shown in ₹ INR
User opens app in UAE    →  Detects AE locale  →  All figures shown in د.إ AED
User opens app in Japan  →  Detects JP locale  →  All figures shown in ¥ JPY
```

**How it works, end-to-end:**

1. **Auto-Detection** — IP geolocation identifies the user's country on first load and sets the correct default currency immediately
2. **Live Exchange Rates** — Exchange Rate API provides real-time rates so all AI-generated cost estimates are accurate to the day
3. **Local Currency Input** — Users enter their budget in their own currency (e.g., "₹50,000"); the AI reasons natively in that amount — no conversion steps, no rounding confusion
4. **Manual Override** — Any currency can be pinned from Settings, useful for expats or travelers who prefer to plan in the destination's currency
5. **Consistent Display** — Currency symbol, formatting, and decimal convention follow locale standards across every single screen

**30+ Supported Currencies:**
`INR` · `USD` · `EUR` · `GBP` · `AED` · `SGD` · `JPY` · `AUD` · `CAD` · `MYR` · `THB` · `HKD` · `CHF` · `SAR` · `KWD` · and more

## 🔐 Security & Privacy

- Geolocation data used for currency and language detection is processed **client-side only** — never stored or transmitted to our servers
- User preferences (language, currency, theme) are persisted via Zustand's localStorage adapter — **no account required** for full personalization
- All API keys are stored exclusively in **server-side `.env` files** and are never exposed in the frontend bundle
- Twilio SMS notifications are **opt-in only**, with explicit user consent required at trip creation
- Cloudinary media uploads are served over HTTPS with **signed URLs** to prevent unauthorized access

---

## ♿ Accessibility & Inclusivity

- Full **RTL (Right-to-Left)** layout for Arabic and other RTL languages
- **WCAG 2.1 AA** color contrast compliance across all UI components
- Screen-reader-friendly **ARIA labels** on all interactive elements
- Language and currency personalization are available **without account creation** — removing barriers for first-time and low-tech users

## 🚀 Installation & Setup

### Prerequisites
- Node.js ≥ 18.x
- npm ≥ 9.x

### 1. Clone the Repository
```bash
git clone https://github.com/jayachandran-jk/Odoo-x-KAHE-Coimbatore-Hackathon-26-Traveloop.git
cd Odoo-x-KAHE-Coimbatore-Hackathon-26-Traveloop
```

### 2. Setup Backend
```bash
cd backend
npm install
cp .env.example .env      # Add your API keys (see APIs Used section above)
npx prisma generate
npx prisma migrate dev
npm run dev
```

### 3. Setup Frontend
```bash
cd ..
npm install
npm run dev
```

> The app runs at `http://localhost:5173` · API at `http://localhost:3000`

### API Keys Required
Obtain keys from: [Google AI Studio](https://aistudio.google.com) · [Groq](https://console.groq.com) · [Unsplash](https://unsplash.com/developers) · [Cloudinary](https://cloudinary.com) · [OpenWeather](https://openweathermap.org/api) · [Mapbox](https://mapbox.com) · [ExchangeRate-API](https://exchangerate-api.com) · [Twilio](https://twilio.com)
